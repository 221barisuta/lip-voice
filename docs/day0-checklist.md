# Day 0 チェックリスト（患者さんの PC への導入と最初の確認）

目的: 実際の姿勢・カメラの角度・この PC で、収集を始めてよいかを、1 回の訪問（30〜40 分）で判断する。
患者さんの負担を減らすため、導入と確認は**家族と開発者**で行い、患者さん本人にはカメラの前で口パクしてもらう時間だけをお願いする。

## 0. 持ち物・事前確認
- [ ] 導入パッケージ `lipvoice-win-*.zip`（USB）。`scripts/make-release.sh` で作る（約 150MB）
- [ ] 本人（または代理の家族）の同意の確認（記録するのは口元の切り出しと特徴点だけ、顔全体は保存しない、いつでも削除できる、など）
- [ ] 視線入力ソフトを使っていない時間帯（導入中に PC を占有するため）
- [ ] デバイスマネージャでカメラの項目を確認（通常のカメラと、`Infrared` / `IR` を含む項目が別にあるか）

## 1. 導入（約 10 分）
1. zip を PC のデスクトップなどに展開する（展開先のパスは日本語を含んでもよいが、導入先は `C:\LipVoice` に固定される）
2. `install.cmd` をダブルクリック。「ハッシュの確認 → Python（専用）→ LipVoice → モデル → ショートカット」の順に進む
   - VC++ ランタイムが無い PC では、許可の確認が 1 回出る
   - 失敗したら、画面を写真に撮る（エラー文が必要）
3. デスクトップに `LipVoice` と `LipVoice check (bench)` ができる
- システムの設定は変えない。消すときは `C:\LipVoice` とショートカット 2 つを削除するだけ

## 2. カメラの特定（約 3 分）
- `C:\LipVoice\cameras.cmd` を実行する。カメラの名前の一覧と、番号ごとの解像度が出る
- 通常のカメラ（例 640×480 以上）の番号を確認する。**IR カメラ（解像度が小さい、白黒）が `0` になっていたら**、`C:\LipVoice\data\patient\config.json` の `"camera_source"` を通常のカメラの番号に変える
- 夜間アラートに IR を使う検討は、あとの段階（今回は通常のカメラだけ）

## 3. 設定の確認（約 1 分）
`C:\LipVoice\data\patient\config.json` が次のとおりか確認する。
- [ ] `"date_override": ""`（空）、`"auto_save": false`
- [ ] プロフィール名が `patient`（`default` / `test` ではない）
- [ ] `still_sec` 1.5、`max_sec` 15、`session_minutes` 5（患者さん向けの既定。必要なら収集画面の設定で変える）

## 4. bench（約 40 秒。いつもの姿勢・カメラの位置で）
1. 実際に使う姿勢・カメラの角度・部屋の明るさにして、`LipVoice check (bench)` を実行する
2. 1 段目（20 秒）: 口を閉じて、楽にして静止する
3. 2 段目（10 秒）: 家族の合図で Enter。フレーズ（例「痛い」「暑い」）を 3 回、ふだんどおり口パクする
4. 結果が `C:\LipVoice\data\patient\logs\bench-*.json` に保存される（顔の画像は含まない）

| 項目 | 合格 | 条件付き（調整して測り直す） | 不合格 |
|---|---|---|---|
| 顔の検出率 | 95% 以上 | 70〜95%（位置・明るさ・`camera_rotate`・`face_detection_confidence` を調整） | 70% 未満 |
| fps | 15 以上 | 10〜15（`idle_fps`、解像度 480×360 を試す） | 10 未満 |
| 顔検出の処理時間（95%） | 50 ms 以下 | 50〜80 ms | 80 ms 超 |
| 顔の傾き / 回転 | 35° 以下 | 35〜45° | 45° 超 |
| 口パクとノイズの差（SNR） | 3 以上 | 2〜3 | 2 未満 |
| 閾値の候補 | 0.02 未満 | — | 0.02 以上（静止してもノイズが大きい） |

- **顔の検出率が低い・「画像内の回転」が大きい**時は、bench が自動で、映像の向き（0/90/180/270°）ごとに顔が検出できるかを調べ、`config.json` の `"camera_rotate"` に入れる値を案内する。その値に書き換えて、もう一度 bench を実行する
- どの向きでも検出できない時は、収集画面の「カメラ位置の確認」で映像を見る（顔が映っているか、小さすぎないか、暗くないか）。IR カメラを掴んでいる場合は `cameras.cmd` で別の番号を探す
- 「不合格」が 1 つでもあれば、収集に進まない。カメラの位置・角度・明るさ・遮蔽（管、テープ、マスク）を見直して、bench をやり直す
- 結果の写真（またはテキスト）を開発者に送る。判断と、閾値の反映のしかたを案内する

## 5. 視線入力ソフトとの同居（約 5 分）
1. 視線入力ソフトを普段どおり起動する
2. `LipVoice` を起動する（収集画面が開く）
3. [ ] 視線入力ソフトが引っかからずに使えるか
4. [ ] タスクマネージャで、CPU の合計が 70% 未満か（LipVoice は低い優先度で動く）
5. 重いときは、収集画面の設定や `config.json` の `idle_fps` を下げる、または LipVoice を使うときだけ起動する運用にする

## 6. 試し録画（約 5 分）
1. 収集画面の「設定」を開き、`bench` の閾値の候補（または収集画面の「校正」ボタンの結果）を反映する
2. 1 つのフレーズを 3 回、スペースを離して口パクして、保存する
3. [ ] 3 本とも「口が止まったので終了」で保存できた（「最大時間で終了」が混じる場合は、止まるまでの秒数を長くする）
4. [ ] 「口の動きなし」ばかりになる場合は、閾値を下げるか、カメラ位置・明るさを見直す
- この試し録画は、収集画面の「直前の保存を取り消す」で削除できる（学習には使わない場合は消す）

## 7. 記録（開発者が残す）
- 日付、PC・カメラの機種、bench の結果（上の表）、設定の変更点、気づいたこと
- BitLocker（デバイスの暗号化）の状態: 設定 → プライバシーとセキュリティ → デバイスの暗号化（Home でも使える機種がある）。**オフなら、データの保存先を暗号化できないことを同意の説明に含める**

## 8. 収集の進め方（患者さんの負担を減らす）
- 1 セッション 5〜10 分、1 回 10〜20 本。休憩をはさむ。疲れた日は無理をしない
- 別々の日が **3 日以上**あればよい（評価は最新の日、学習はそれ以前）。1 日 10 フレーズを 1 回ずつ、でも始められる
- 最初に録るフレーズは、日常で使う頻度が高く、口の形が違うもの（「痛い」「暑い」「寒い」など）から
- 認識画面で選ぶ使い方（実使用）でもデータは貯まる。収集が負担なら、そちらを中心にしてよい

## 9. 持ち出し（Mac での学習）
- 患者さんの PC: `LipVoice` を終了してから（起動中でも可）、`C:\LipVoice\venv\Scripts\lipvoice.exe --home C:\LipVoice\data --profile patient export <USB のドライブ>:\`
- Mac: `lipvoice --home ~/LipVoice-patient import <USB 内の lipvoice-export-patient-...>` → `lipvoice --home ~/LipVoice-patient --profile patient check` → 学習 `train`
- 学習したモデルを戻す: Mac で `export <USB> --models-only --force` → PC で `import-models <USB 内のフォルダ> --activate` → LipVoice を再起動
- USB は暗号化（BitLocker To Go）し、Mac での保管期間と削除の方法を、同意の説明に含める。使い終わった書き出しは USB から削除する

## 付録: コードだけの更新（導入済みの PC）
- Mac で `scripts/make-update.sh` を実行すると、小さな更新 zip（約 150KB）ができる
- PC で展開して `update.cmd` をダブルクリック（`C:\LipVoice` の `lipvoice` だけを入れ替える。データ・設定・依存はそのまま）
