# lip-voice

口パク（声を出さない口の動き）をカメラで読み取り、登録した定型フレーズを判定して音声で再生するアプリ。
声を失ったが口は動かせる人（気管切開後の ALS 患者など）が、自分のフレーズを自分専用のモデルで認識させることを目指す。

## 特徴
- **利用者の PC の中だけで動く。ネットがなくても動く**（初回に顔検出のモデルを取得するときだけネットが必要）
- 顔全体の映像は PC の外に出さない。保存するのは口元の切り出しと特徴点だけ
- 利用者のデータで学習し、口の動きの変化に合わせて再学習できる
- データはプロフィールごとのフォルダに保存。バックアップは Google ドライブの同期フォルダへ（予定）

## 状態
ステップ2a（収集基盤）と 2b（学習・評価・テスト用の認識画面・評価画面）まで実装済み（合成データと、動画ファイルをカメラにした環境で確認。実機は未確認）。バックアップ（2c）、常時監視と夜間アラート（ステップ3）はこれから。
詳細は [docs/spec.md](docs/spec.md)。以前の Google ログイン + Cloud Run 版は、コミット `e83e7e7` までの履歴に残っている。

## セットアップ（開発: Mac / Linux）
Python 3.10 以上、Node 22 以上が必要。
```
scripts/setup-dev.sh          # Python の環境、画面のビルド、顔検出モデルの取得
app/.venv/bin/lipvoice run --open
```
- カメラの番号を調べる: `lipvoice cameras`。指定して起動: `lipvoice run --source 1`
- 動画ファイルをカメラの代わりに使う（試験用）: `lipvoice run --source 動画.mp4`
- 実機の確認（Day 0）: `lipvoice bench --seconds 20`（顔の検出率・fps・処理時間・顔の傾き・静止時のノイズ）
- データの整合性を検査する: `lipvoice check`（`--repair` で孤児ファイルを退避）
- Mac では初回に、ターミナル（または使っているアプリ）にカメラの許可を出す

## 試験の手順（開発者の顔で、3 日分をまとめて集めて、学習 → 評価 → 認識まで確かめる）
```
scripts/setup-dev.sh --train                              # 初回のみ（学習用の torch も入れる）
app/.venv/bin/lipvoice --profile test run --open         # 収集・認識・評価の画面
```
1. 収集画面の「設定 → 試験用」で、**撮影日の上書き**を `day1` にし、**自動保存**をオンにする。「1 セッションの長さ」を 60 分にする
2. スペースを離して口パクする（口が止まると自動で終わり、保存して次のフレーズへ）。10 フレーズ × 10 回 = 100 本
3. 撮影日を `day2`（100 本。照明や姿勢を変える）、`day3`（10 フレーズ × 5 回 = 50 本）に変えて続ける。「フレーズではない動き」（あくび、咳、口を湿らせる、飲み込み、自由な口パク）も、各日に数本ずつ録る
4. アプリを止めて（Ctrl+C）、学習と評価: `app/.venv/bin/lipvoice --profile test train`（数分）
5. もう一度起動して、「認識（テスト）」で試し、「評価」で正解率・取り違え表・自動発話の判断材料を見る
6. 試験が終わったら、撮影日の上書きと自動保存を**オフ（空）に戻す**。実際の収集は別のプロフィール（`--profile patient` など）で行う

合成データで流れだけ確かめる（収集不要）: `lipvoice --profile synth synth` → `lipvoice --profile synth train`

## 実際の収集（患者さん本人の PC。特徴点だけを保存）
- スペースキーを押して離すと録画が始まり、口が止まって 1 秒（または 10 秒）で自動で終わる。Enter＝保存、Backspace＝撮り直し、Esc＝中止。大きなボタンも使える
- 導入時に、実際の姿勢・カメラの角度で `lipvoice bench`（Day 0 の確認）を実行する。顔の検出率、fps、処理時間、顔の傾き、静止時のノイズが出る
- 患者さん本人のデータは、本人の PC（プロフィールを分ける）で、特徴点だけを保存する。動画をそのまま PC の外に出さない

## 学習・評価・モデル
- `lipvoice train`: 日ごとの交差検証（その日を評価、残りの日で学習）で A（DTW）と B（1D-CNN）を評価し、全日で学習し直したモデルを `models/<日時>/` に保存して使う（`--no-cnn` で A のみ、`--epochs`、`--use-duration`）
- `lipvoice models`: 版の一覧。`lipvoice models --activate <版>` でロールバック
- 評価は撮影日で分ける（ランダムに分けない）。日付が 1 日分しかないと評価できない

## データの置き場所
`~/LipVoice/<プロフィール>/`（`LIPVOICE_HOME` と `--profile` で変更）。中身は `config.json`、`lipvoice.db`、`clips/`、`models/`。
1 クリップは約 200KB（250 本で約 50MB）。開発者のテストデータと本人のデータは、別のプロフィールにする。

## 開発
```
cd app && .venv/bin/python -m pytest        # テスト
cd web && npm run dev                       # 画面の開発（別端末で LIPVOICE_TOKEN=dev lipvoice run --dev、VITE_LIPVOICE_TOKEN=dev）
```

## 安全上の前提
- 緊急の呼び出しはこの仕組みに頼らない。既存の手段を併用する
- 自動発話は、取り違えが少ないと確認できるまで OFF
- 顔由来のデータは、OS のディスク暗号化で守る（Mac は FileVault、Windows はデバイスの暗号化）
